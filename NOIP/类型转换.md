# 类型转换

## 自动转换与强制转换
- 规则：小的类型可以自动转化为大的类型，为自动转换
-       如果需要反方向，需要强制转换
- Tips:
    - 强制转换的过程中可能会发生丢失信息，成为信息的截断
    - chat ==> short ==> int ==> longlong ==> float ==> double
    - 
    - 强制转换语法：
    - (要转换的类型)变量名

## 两个浮点数的比较
- 两个浮点数的比较可能会出现我们不期望的结果
- 原因：计算机使用二进制进行数据的存储。
        - 对于整数来说，二进制可以完美表示
        - 而对于小数来说，在二进制中却是一种无线不循环的小数
        - 使用这样的书进行相加减比较的时候
        - 并不是我们所期望的相加减运算
        - 由于无线不循环的存在，计算机会认为这两个个浮点数的相加减的结果与比较值不一致
        - 所以显示布尔值为 0

## 四舍五入
- 早期的c 中没有提供函数
- c++99标准中有 ceil floor round 函数
- floor():不大于它的最大整数 向下取整
- ceil():不小于它的最大整数  向上取整
- round():临近它的整数
- 在c++的除法运算中(/)，如果两个int类型的书进行相除，会自动舍去小数部分，保留整数部分
